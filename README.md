# CV Agape Sinar Nirwana (ASN) — Company Profile

Website profil perusahaan resmi **CV Agape Sinar Nirwana (ASN)**, General Supplier & Mining Support Solutions di Indonesia.

## 🚀 Fitur Utama

- **Next.js 16 (Turbopack)** & React Server Components.
- **Tailwind CSS** dengan dukungan penuh Dark Mode dan Light Mode.
- **Katalog Produk Terstruktur** (Mining Tools, Safety & Heavy Equipment, Fasteners, Electrical, CCTV).
- **Formulir RFQ (Request for Quotation)** terintegrasi dengan WhatsApp & Email.
- **Halaman Lengkap**: Beranda, Solusi Industri, Katalog Produk, Tentang Kami (Profil, Visi, Misi, 6 Keunggulan), dan Kontak.
